# Jeltörő

Lehallgatóállomás 1957-ből

Játszható a böngészőben: https://buhallamate-del.github.io/ Morse, eltolt ábécé, számállomás és kép a zajban (vízesés-spektrum). Négy fejezet, a harmadik hat világ adásaiból áll; a végén összeáll az üzenet, amely minden világon átfut. Heti adás: mindenkinek ugyanaz az öt adás, az idő számít.:Jel-toro/

Egyetlen fájl (`index.html`), a mentés a böngésző helyi tárhelyén él. A heti verseny egy nyilvános MQTT üzenetközvetítőn (HiveMQ) megy át; a könyvtár: `vendor/mqtt/` (MIT licenc). A játék a szerző többi játékával közös naplót vezet (multiverzum).
